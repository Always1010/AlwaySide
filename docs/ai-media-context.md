# 图片、音频与会话

本文说明提问时会发送哪些内容，以及历史记录能保留什么。操作步骤见[使用说明](usage.md)。

## 提问时发送什么

| 操作 | 发往所配置 API 服务的内容 |
| --- | --- |
| 截图或框选提问 | 本次图片、问题和相关文字上下文 |
| 仅文字追问 | 问题和相关文字上下文，本轮不附图片 |
| 结束录音并处理 | 录音先发往转写接口；需要翻译或回答时，再使用转写文字提问 |
| 选中文字提问 | 所选原文、问题和相关文字上下文 |

开启屏幕共享或显示悬浮球，不会持续上传画面。取消录音会丢弃当前片段，不发送转写请求。

录音达到时长上限默认停止并丢弃，不发起转写。在「设置 → 历史与媒体 → 达到上限后」可改为保留并提示，等待明确确认后再发送，或选择自动处理。手动结束的行为仍由音频自动处理开关决定。

「AI 服务」中的图文问答与音频转写分别保存服务商卡片，每个服务商在每个用途中只保留一张；卡片选择该服务商已有的 API 密钥、模型和默认参数。Key 及其 API 地址、接口信息统一在「管理 API 服务」编辑。首项保存后自动选中，后续新增保留当前选择。点击服务行切换，行尾图标编辑或删除。两用途可共用服务和 Key，也可分开：录音文件只发送到所选转写服务，生成翻译或解释时，转写文字再发送到所选问答服务。切换问答服务后继续已有会话，会把本轮需要的文字上下文发送给新服务；不会自动把媒体发送给所有已保存服务。API 服务如何处理收到的内容，以所用服务的数据政策为准。协议差异见[API 服务商与接口格式](api-providers.md)。

仅原始转写只需要已选用的音频转写卡片，不需要问答密钥；翻译或回答才使用图文问答配置。未配置转写不影响截图或文字提问。首张卡片保存后自动选用，后续新增不改变当前选择；保存或选用都不会自动上传媒体。

## 图片追问

“沿用原图”会在请求中附上当前图片，便于继续询问图中的细节；“更新画面”会取得新截图；“仅文字”只延续文字讨论，不能保证模型仍能查看原图中的细节。

当前会话能使用图片，不代表图片已经长期保存。默认会随历史保存会话首张截图和当前追问图片；关闭历史图片保存后，仍可在当前会话中使用图片，但之后从历史恢复时可能需要重新截图。

## 录音与转写

实验室回听字幕默认由音频对话中的明确操作单独发起。开启「音频提问同时生成字幕」后，尚无原文的音频处理会改用 Whisper 字幕方案，只识别一次，原文和时间轴保存后即可用于问答，中文字幕独立继续。普通转写卡片不参与这次处理，字幕失败也不自动回退另一次转写；回答重试和后续追问复用已得到的原文。识别未完成时取消会中断字幕任务，原文完成后取消回答不取消中文翻译。此实验目前按英语识别，不采用日常转写模型、提示词或语言设置。Whisper 保存英文 SRT、中文 SRT 和生成检查点，原文与译文共用时间轴。切换语言或重复回听不上传音频；已有会话原文不因开启实验或手动重做字幕而自动改写。

字幕生成只使用实验室单独选择的 OpenAI 官方 Key 与翻译模型。所选录音先发往转写接口，原文条目再用于中文翻译；不会自动换厂商或模型，不自动重试。中文默认整段一次翻译，可在实验室开启「分批翻译」。只剩纯文字的旧对话不能恢复可靠时间轴。尚未长期保存的录音，在选择「保留本段录音并制作字幕」，或开启上述实验后发起音频处理时，会为字幕长期保留；不改变全局音频保存设置。删除会话或原始音频一并删除其字幕，取消任务保留成功检查点。

转写是把声音转成原语言文字，翻译或总结则根据转写生成回答。原始转写可展开查看，也能作为后续追问的资料。

录音时长上限填 0 表示不限时长，仍受设备存储和单个 WAV 文件约 2 GiB 的限制；达到文件大小限制时也按「达到上限后」选项处理。较长录音会按顺序分段转写，再合并原文。

转写提示与音频语言统一在「设置 → 提示词」保存，由所有转写服务共用；切换服务商、模型或密钥不改变它们，转写服务页不再提供转写参数。提示词模板可同时保存和应用这两项。修改后用于之后新发起的转写，不自动重做已有原文；旧会话追问继续复用已有转写。首次升级仅在全局语言字段缺失时迁移当前启用服务的旧语言，明确选择自动识别后不会恢复旧值。

转写完成后的追问复用文字，不会再次上传原始录音。转写成功而回答失败时，主动重试也会复用原文；变更转写卡片、Key 的 API 地址或接口信息、密钥、模型、提示词或凭证版本后，需要转写的录音不复用另一组配置的缓存。切换图文问答配置不会使独立转写缓存失效。原始录音默认随会话长期保存；关闭长期保存后，只临时保留用于处理和当前会话回听，应用进程结束后不能保证恢复。

「设置 → 历史与媒体」中的「随历史长期保留音频」开启时，新完成的录音会在后台随会话长期保存，不依赖转写或回答成功；取消录音仍直接丢弃。历史对话标题栏的播放图标可回听、暂停和继续，外围圆环随剩余时长逐渐消失，暂停时保持进度；播放期间可翻看聊天和继续追问，离开聊天页停止播放。已保存但尚未转写的录音，可在发送问题后继续处理。

达到录音上限后丢弃的片段不保存。选择保留并提示时，确认前仅留在当前悬浮会话，不写入历史，也不上传；确认转写后才按历史音频开关保存。停止助手或应用进程退出后，尚未确认的录音不保留。

音频开关默认开启，只影响之后完成的录音，不补存旧录音；关闭不会清理已保存音频。历史音频总容量上限为 512 MiB，达到上限或存储失败时会提示，当前会话仍可继续处理临时录音。回听本地音频不会上传文件。

## 本地历史

会话文字、转写、所选原文和已保存图片、音频存放在应用私有目录，并排除 Android 备份。删除或淘汰会话时，一并删除关联图片和音频；空间不足导致媒体保存失败时会显示提示。

普通历史默认保留 500 段，数量可在「设置 → 历史与媒体」调整，超出时按普通历史保留队列清理最早的会话。收藏及其已保存媒体不参与自动淘汰，也不占普通历史名额。取消收藏会重新排到保留队列最新位置，原聊天时间与标签保留。继续聊天会更新普通历史保留优先级。

旧版会话档案会完整迁移为独立会话文件，不在迁移时裁减历史或清理媒体。本地单段会话暂不设消息条数和固定文件大小上限，继续追问不裁掉早期记录；发送给模型的上下文仍按请求规则选取。保存失败会提示，不通过删除收藏腾出空间。原有图片和音频总容量限制继续生效。

收起小窗、取消请求和删除历史是不同操作：收起后可以继续打开会话，取消会停止当前处理，删除则清理本机记录。删除本地历史不会撤回已经发送给 API 服务的内容。

本版升级需要重新配置 AI 服务，不自动迁移旧版 v1–v3 的服务绑定；已保存历史、图片和音频，以及提示词和外观设置仍保留。重新配置后继续历史对话时，会向新选用的服务发送本轮需要的内容。
