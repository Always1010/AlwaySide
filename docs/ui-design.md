# 界面设计约定

Android 界面保留单窗口导航、细线图标、紧凑列表与独立结果小窗。设置参考分组卡片与行内值的布局，使用 Google Material Components 1.14.0 的真实卡片、按钮、输入框、开关、滑块、复选框及对话框；工具栏图标采用低强调样式。

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 页面与输入底色 | `#FFFFFF` | `#151719` |
| 次级底色与用户消息 | `#F2F4F5` | `#24272B` |
| 正文 | `#202428` | `#F5F6F7` |
| 次要文字 | `#535B64` | `#BEC3C9` |
| 输入提示 | `#68717C` | `#ABB2BB` |
| 分隔与边框 | `#9099A4` | `#717983` |
| 黑色方案强调 | `#191C20` | `#E8EAED` |
| 蓝色方案强调 | `#2155CD` | `#9CC2FF` |

明暗模式默认跟随系统，也可固定浅色／深色；黑色／蓝色方案分别定义按钮、选择、聚焦与前景色，应用页面、对话框和悬浮结果一致适配。共享样式由 `Ui.kt` 提供，Material3 主题配置 Context 并通过 AppCompatDelegate 接入平台 Activity。保留原 Activity 会话保留机制。图标使用 24 单位细线矢量，通过 `PrototypeIcons.kt` 映射；通常显示为 15–18dp，保留 44dp 触控区域。

设置文字项默认显示名称、只读值与编辑铅笔，点编辑后才出现 Material 输入框及行内勾号／叉号。最多一个文字编辑器活跃，保存只更新最新配置的对应字段；取消不写入。API Key 不回填，也不放假掩码，只显示保存状态。选择项带箭头和当前值，开关与滑块采用各自明确的保存时机。

正文操作使用黑色／蓝色实色 MaterialButton；返回、添加、编辑、删除、取消和行内保存采用透明背景图标，仅按下时显示反馈，不加常态边框。颜色采用色块和可视调色板，确认即保存。顶部没有统一保存按钮。

- 普通记录列表没有常态卡片描边；标题 13sp、摘要 11sp、时间状态 10sp。长按进入多选，选中行与复选框突出状态，顶部固定数量、删除和取消；多选时隐藏普通品牌与导航区域，返回先取消。
- 设置分类进入详情；分组标题在圆角卡片外，名称和值在行内，辅助说明放在相应卡片中。无描边的 18dp 圆角容器组织相关设置。
- 对话记录、分类设置及聊天在同一应用窗口中切换，使用统一的标签栏与返回规则。设置详情返回分类；从聊天进入设置后返回原聊天，避免 Activity 动画与任务栈制造跨应用观感。
- 应用内打开记录进入完整聊天页；悬浮球触发独立的小窗。助手回复以正文呈现，用户问题使用轻底色消息。
- 结果小窗默认 320 × 340dp、15dp 圆角、细边框；头部显示来源图标、12sp 标题和固定按钮。未固定时点外部收起，支持移动及调整尺寸。
- 悬浮球默认视觉直径 28dp、透明度 55%，触控范围 48dp。菜单贴球显示，宽 164dp，使用细线图标、12sp 文字与分组分隔。

字号使用 sp，尺寸和间距使用 dp；系统字体缩放、实际屏幕可用范围及用户保存的窗口几何会影响最终尺寸。原型尺寸用于默认布局，不覆盖用户外观与窗口设置。
