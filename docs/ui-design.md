# 界面设计约定

Android 界面保留已确认原型的单窗口布局、细线图标、紧凑列表与独立结果小窗。依据后续可用性反馈，配色采用白色／中性黑灰底，并提高可编辑控件与操作按钮的辨识度。

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 页面与输入底色 | `#FFFFFF` | `#151719` |
| 次级底色与用户消息 | `#F2F4F5` | `#24272B` |
| 正文 | `#202428` | `#F5F6F7` |
| 次要文字 | `#535B64` | `#BEC3C9` |
| 输入提示 | `#68717C` | `#ABB2BB` |
| 分隔与边框 | `#9099A4` | `#717983` |
| 强调 | `#246342` | `#8DDBAE` |

主题默认跟随系统，也可在应用外观固定选择浅色／深色；应用页面、自己的对话框和悬浮结果一致适配。共享样式由 `Ui.kt` 提供，平台控件通过主题配置 Context 适配。图标使用同一套 24 单位坐标的细线矢量图形，通过 `PrototypeIcons.kt` 统一映射。图标通常显示为 15–18dp，图标按钮保留 44dp 触控区域，避免视觉大小与点击范围绑定。

输入框使用清晰中性边框、深色实输文字、灰色提示，聚焦时显示强调色边框；禁用状态改变底色与字色。设置字段的提示额外使用斜体及“请输入／示例”措辞，标签旁显示填写状态。保存的 API Key 状态在框外显示，框中不放真实旧密钥或假掩码。

操作按钮使用强调色文字／边框或实体填充，选择控件带箭头与单选状态，避免与可编辑字段混淆。文字按钮自适应高度，保存按钮仅有修改时启用，保存成功后恢复禁用。颜色采用命名色块与可视调色板，调整先预览，确认后修改草稿，保存后持久化。

- 应用首页为品牌标题、说明、对话记录／设置导航和细分隔记录列表。列表标题 13sp、摘要 11sp、时间状态 10sp。
- 设置使用分类首页进入独立详情；标题、字段与说明保持层级，保存操作放在详情顶部，避免重复操作区。
- 对话记录、分类设置及聊天在同一应用窗口中切换，使用统一的标签栏与返回规则。设置详情返回分类；从聊天进入设置后返回原聊天，避免 Activity 动画与任务栈制造跨应用观感。
- 应用内打开记录进入完整聊天页；悬浮球触发独立的小窗。助手回复以正文呈现，用户问题使用轻底色消息。
- 结果小窗默认 320 × 340dp、15dp 圆角、细边框；头部显示来源图标、12sp 标题和固定按钮。未固定时点外部收起，支持移动及调整尺寸。
- 悬浮球默认视觉直径 28dp、透明度 55%，触控范围 48dp。菜单贴球显示，宽 164dp，使用细线图标、12sp 文字与分组分隔。

字号使用 sp，尺寸和间距使用 dp；系统字体缩放、实际屏幕可用范围及用户保存的窗口几何会影响最终尺寸。原型尺寸用于默认布局，不覆盖用户外观与窗口设置。
