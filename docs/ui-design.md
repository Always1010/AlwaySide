# 界面设计约定

本文供开发者维护界面时参考。用户操作见[使用说明](usage.md)，产品概览见[README](../README.md)。

## 产品原则

AlwaySide 是可自定义的 Android 悬浮 AI 助手，围绕截图、选中文字和应用内音频提供提问、结果阅读与继续追问。翻译与语言理解是主要场景之一，同时支持截图解释、音频总结和按提示词处理内容；界面入口保持通用，不把产品限定为语言学习工具。

- **先呈现内容和操作**：默认只保留完成当前任务所需的入口、输入与结果，延续现有导航和组件，避免增加重复入口。
- **图标与按需帮助**：可识别操作优先使用细线图标，配无障碍名称及长按说明；需要解释的规则先精简，统一放在圆圈 i 中，默认隐藏。
- **让自定义有明确位置**：提示词、菜单、手势与服务配置在各自设置中调整；结果窗保留本次提问与追问所需的控制，不重复堆放全局设置。
- **保留影响判断的信息**：在相关操作处简明交代数据发送、费用、权限、数据丢失和不可逆后果。正文文案面向最终用户，不写开发约束、实现细节或验收说明。
- **明确实验边界**：字幕制作面向英语录音与简体中文译文，聊天点读由用户主动选中文字发起；实验功能默认关闭，不暗示实时翻译或其他应用自动化。

## 视觉与交互

Android 界面保留单窗口导航、细线图标、紧凑列表与独立结果小窗。统一使用 Google Material Components 1.14.0 的 MaterialToolbar、MaterialTextView、卡片、按钮、输入框、开关、滑块、复选框及对话框。导航、排版和编辑面板共同遵循 Material3 层级；工具栏图标采用低强调样式。

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 页面与输入底色 | `#FFFFFF` | `#151719` |
| 次级底色与用户消息 | `#F2F4F5` | `#24272B` |
| 正文 | `#202428` | `#F5F6F7` |
| 次要文字 | `#535B64` | `#BEC3C9` |
| 输入提示 | `#68717C` | `#ABB2BB` |
| 分隔与边框 | `#DCE0E5` | `#41464E` |
| 黑色方案强调 | `#191C20` | `#E8EAED` |
| 蓝色方案强调 | `#2155CD` | `#9CC2FF` |

明暗模式默认跟随系统，也可固定浅色／深色；配色默认蓝色，也可选择黑色。黑色／蓝色方案分别定义按钮、选择、聚焦与前景色，应用页面、对话框和悬浮结果一致适配。共享样式由 `Ui.kt` 提供，Material3 主题配置 Context 并通过 AppCompatDelegate 接入平台 Activity。保留原 Activity 会话保留机制。图标使用 24 单位细线矢量，通过 `PrototypeIcons.kt` 映射；独立操作图标显示为 20dp，保留 48dp 触控区域。

桌面应用图标使用 Android 自适应图标：背景为完全不透明的浅粉色 `#E3A6B3`，铺满整个图层；前景沿用悬浮球的白色空心星芒和右上角小星芒。前景在系统可见区域内保持与确认稿一致的比例，并位于裁切安全区；外轮廓由桌面统一裁切为圆角方形、圆形等形状，不在资源内预制圆底或白边。桌面图标颜色固定，独立于悬浮球的用户配色和不透明度设置。

设置文字项默认显示名称与只读值。点击对应项后，在 BottomSheetDialog 中显示 Material 输入框和保存／取消按钮。最多一个文字编辑器活跃，保存只更新最新配置的对应字段；取消不写入，关闭前检查未保存修改。API Key 不回填，也不放假掩码，只显示保存状态。选择项带箭头和当前值，开关与滑块采用各自明确的保存时机。页面允许系统截图。

设置正文操作与编辑保存使用黑色／蓝色实色 MaterialButton，次要操作使用文字按钮；返回、添加、编辑、删除和取消等图标操作采用透明背景，仅按下时显示反馈，不加常态边框。正文按钮按内容宽度排列。颜色采用色块、可视调色板与 Material 色相滑块，确认即保存。顶部没有统一保存按钮。

- 首页直接展示记录列表，工具栏右侧为悬浮球开关与设置图标，不显示标签栏。新建文字对话使用 56dp 圆形 FloatingActionButton，距列表页右侧 28dp、底部 88dp；与悬浮球开启按钮共用主题强调底色及前景色。全部对话、收藏、标签及未标记列表均显示加号；设置及聊天页不显示，抽屉覆盖按钮，多选时隐藏。列表底部留出 168dp，使末条记录能滚动到按钮上方。全部对话、我的收藏、标签及未标记列表在标题栏下方保留圆角搜索栏，即时匹配当前列表内的标题、正文、转写、所选原文和标签；清空按钮与系统返回均可清除查询，切换列表清空搜索。搜索栏独立于滚动内容，输入筛选不重建输入框。普通记录列表没有常态卡片描边；标题使用 Material3 TitleMedium，摘要使用 BodyMedium，时间状态使用 BodySmall。长按至少 700ms（系统设置更长时跟随系统）进入多选，移动取消长按，触发时轻震。多选顶部左侧全选当前筛选范围的全部结果，选齐后可取消全选，中间显示数量，右侧叉号退出；收藏、标签、删除固定在底部，零项保持多选并禁用批量动作。进入及退出多选保留筛选和滚动位置，旋转与主题重建恢复模式及选中项；多选时隐藏搜索栏、普通动作与权限提示，暂停左右滑和侧栏滑动。标签支持确认保存时一起收藏未收藏项，关闭面板不改变会话，保留未调整的标签，失败保留编辑。普通条目右滑展开收藏或取消收藏，左滑展开更多与删除，松手仅展开、点击才执行；更多含标签设置与选择此会话，删除仍需确认。一次仅展开一条，点内容或空白、滚动及系统返回先收起动作区；从屏幕边缘起手保留系统与侧栏手势，无障碍动作提供等效入口。
- 搜索框右侧独立放置 48dp 时间筛选图标按钮，与输入框间隔 8dp，复用细线调节滑块图标。未设置时使用次要色、透明底；已设置时使用主题浅强调底色、强调图标及 6dp 圆点，无障碍状态及长按说明提供当前日期范围。通过 Material 对话框分别选择起止日期，原生日期选择器沿用应用主题；确认才应用，取消不更改，清除仅移除日期条件。详细规则放在对话框标题右侧圆圈 i 中。日期按设备本地日历匹配最后更新时间，含起止整天；搜索、收藏及标签条件取交集，不改变原排序。切换列表时清空日期，返回先清关键词再清日期；已应用状态沿用浏览状态保存、恢复，多选时整行隐藏。
- 首次首页显示可跳过的模拟体验卡片，中断后提供继续；设置中的「帮助与引导」保留引导和实际准备两个完整按钮，两者均有底色，次要按钮保留正常文字对比及细边框，始终可见且可点击。目录提供单击菜单与追问、长按截图、双击录音、三击取消四项，按引导项目保留完成记录，使用默认手势教学。引导持续标明模拟、不联网、不消耗 Token；球、菜单和结果窗使用真实功能的纯视图组件，画面、转写和回答为本地示例，不启动真实采集、服务或请求，不写聊天历史。遮罩只绘制目标外侧四块区域，目标保持原色，外有高对比描边和箭头；每次绘制前按实际窗口坐标更新，目标未测量、未显示或不在可见区域时不画遮罩，遮罩层级高于结果窗。追问使用明确标记的预设问题，不接受自由输入配固定回答。用户主动选择后才进入实际使用准备页；填写配置不能显示为连接验证成功。
- 设置分类进入详情；分组标题在圆角卡片外，名称和值按完整宽度的上下层级呈现。常驻说明只保留输入要求、费用提示等必要短句，不重复当前值和开关状态；其余说明先精简，再收进分组标题右侧的圆圈 i，点击打开简短说明弹窗。每组最多一个说明入口，触控区 48dp，提供无障碍名称和悬浮说明；录音上限处理方式的解释放在选择面板中。格式限制放进编辑面板，文件大小、分段转写等技术细节留在使用文档。无描边的 16dp 圆角容器组织相关设置。提示词各自使用完整宽度的摘要卡片，模板动作收在工具栏菜单中。
- 设置选择面板复用应用主题的 `SettingsChoiceSheet`，从底部展开，统一行间距、分隔线和右侧对勾；长列表在面板内滚动。单选项点击保存后关闭；快捷动作手势可多选，取消不写入，保存时统一校验。禁用项置灰，手势占用项保留点击提示。标题使用「选择服务商」「选择 API 密钥」「选择模型」等简短名称；重复添加限制通过禁用状态表达。联网搜索明确显示「关闭／开启」，不支持时禁用「开启」。
- 设置只保留一个「AI 服务」入口，进入后只显示「配置问答服务」「配置转写服务」「管理 API 服务」三行。前两行复用设置列表的标题与下方小字样式：未选用配置显示「未配置」，已选用时显示该配置的「服务商 · 密钥名称 · 模型」，返回本页时更新；管理 API 服务不加摘要。全程只有一条动态工具栏，随当前页面更新标题和动作；顶部返回与系统返回走同一导航逻辑。
- 「管理 API 服务」按实际服务商分组，直接列出 API 密钥，每条 Key 同时包含其 API 地址与接口信息。添加图标先打开服务商选择，再填写 Key 与名称；服务商包含 OpenAI、DeepSeek、Qwen、Gemini、Claude、自定义，不固定展示 VPN 云等具体中转站。所有 Key 编辑集中在此页，不设置独立接入点或密钥授权页面。密钥显示名称及掩码，不回填完整凭证；协议长解释放入说明，基础地址格式留在编辑项。
- 图文问答与音频转写分别以卡片列表管理，每个服务商在每个用途中只保留一张卡片，不额外填写模型配置名称。添加卡片依次选择服务商、该服务商已有 Key、模型及默认参数；首项保存后自动选中，后续新增保留当前选择。左侧圆框表示唯一选中项，点击服务行切换；行尾图标编辑或删除。新增与编辑页分别以「添加／编辑问答服务配置」「添加／编辑转写服务配置」命名，相关操作提示统一称为服务配置。两个用途可共用 Key 或使用不同 Key；仅转写不要求问答 Key。添加、编辑、删除等细线图标提供无障碍名称和悬浮说明。
- 默认参数按当前协议和模型显示适配值，未知留空使用服务默认，可清除旧的不支持值。语音转写提示和音频语言统一位于提示词页，由所有转写服务共用；语言默认自动识别，提供常用语言选择和自定义代码入口，说明收纳在圆圈 i 中。转写服务页不显示转写参数区。提示词模板保存全局转写提示与语言。读取模型列表和文字、示例图片、搜索测试分别触发；保存不能暗示验证成功。测试只使用本地示例，不默认上传当前屏幕。
- S07／S08 为未采用的设置素材，不用于说明当前界面。设置页需要采集真实界面，不另造示意截图。

- 服务名称统一显示为 OpenAI、DeepSeek、Qwen、Gemini、Claude、自定义兼容服务。Qwen 在界面、接入说明和项目文档中均统一使用 Qwen；接口地址和模型 ID 保留实际值。
- 模型选择复用现有列表行与单选弹窗：新建用途配置首次选定可用 Key 后填入适用接口的内置默认型号，点击模型可选精简推荐、手动填写或主动从服务获取。推荐显示默认标记及简短标签，解释统一放圆圈 i；推荐配置由独立 JSON 维护，不联网、不覆盖已有型号或参数。转写只有 OpenAI 有内置推荐，其他服务商全部留空。
- 应用内和悬浮结果标明当前服务与模型；搜索按钮按能力启用，已有不支持的搜索选项仍能关闭。Claude 需要协议续接时，重试图标说明改为“继续生成”，状态说明会再次调用原服务，不自动续接。接口和格式约定见[API 服务商与接口格式](api-providers.md)。
- 对话记录、分类设置及聊天在同一应用窗口中切换。设置详情返回分类，分类页提供左上角返回；从聊天进入设置后返回原聊天，避免 Activity 动画与任务栈制造跨应用观感。
- 应用内打开记录进入完整聊天页；悬浮球触发独立的小窗。助手回复以正文呈现，用户问题使用轻底色消息。完整聊天页的标题栏右端保留更多菜单，复用竖向细线省略号和 MaterialToolbar 溢出菜单。「复制整段会话」与收藏后的标签设置位于菜单内，分别显示复制与标签细线图标。悬浮结果窗标题栏不显示更多入口，「复制最近回答」使用底部复制图标，没有回答时置灰。本地引导共享同一小窗组件。
- 完整聊天页的音频回听使用标题栏播放按钮，不弹窗、不增加进度条。播放中显示暂停图标，外围细圆环按剩余时长从顶部顺时针擦除；暂停保留圆环进度，继续后接着播放，完成后圆环消失并恢复播放图标。按钮保留无障碍名称与长按说明。进度只重绘按钮，翻看消息、复制及追问不打断播放。对话列表可直接回听有录音的记录；关闭「后台播放」时可在列表或当前音频会话中播放，离开这些页面即停止。开启后切换应用或锁屏仍继续播放。
- 结果小窗默认 320 × 432dp、15dp 圆角、细边框；大字体时默认高度随字体比例增加并受屏幕可用范围限制，已保存的用户窗口尺寸继续优先。42dp 紧凑 MaterialToolbar 使用 15sp 粗体标题，并与正文以细线分隔；标题栏从左到右保留丢弃当前对话、固定窗口和在应用中打开三个图标按钮，按钮宽 44dp、高 42dp，图标为 20dp，不设更多菜单。正文为 14sp / 22sp 行高，用户问题为 12sp / 18sp 行高及中性浅底色卡片；仅对悬浮组件定义这些样式，不覆盖整页 Material 排版。卡片不随父窗口的阴影高度混入强调色。未固定时点外部收起，支持移动及调整尺寸；回复按稳定消息行更新。
- 悬浮球默认视觉直径 36dp、不透明度 55%，颜色为预设玫红（`#CC5C74`），触控范围 48dp。菜单贴球显示，默认宽 252dp、圆角 24dp；上方为三列工具网格，48dp 圆形底内为 24dp 细线图标，下方为 12sp 短名称，整格可点击。下方用分隔线独立展示「联网搜索」和「使用默认提问方式」两行复选项，不作为工具参与增删和排序。设置中的「自定义菜单」支持添加、移除、长按拖放排序，以及点击或无障碍前移/后移；立即保存，工具均无强制保留项。默认包含截图、框选、听一段、最近对话、回听、对话记录、设置；关闭悬浮球及取消录音可添加。无音频或未录音时相关工具置灰，录音时原位切换为结束录音。空工具列表显示添加入口；恢复默认只恢复工具排列。大字体时适当加宽并允许文案换行，按实际内容测量高度，超出可用屏幕时滚动。菜单由 `AssistantMenuUi.kt` 构建，球、结果窗和消息行由 `AssistantPresentation.kt` 构建，真实服务与本地教学使用相同视图组件，行为分别由服务或本地步骤回调提供。
- 准备页以四个短操作行展示管理 API 服务、配置问答服务、可选配置转写服务、权限与实际使用，分别直达对应列表。第一步检查已有服务资源，第二步检查当前问答卡片，第三步为可选转写卡片；未保存的草稿不算已选用。下一步突出，详细说明仅在帮助弹窗中呈现；准备中的配置页和普通设置有独立导航身份，逐级返回帮助页，工具栏与系统返回共用入口。
- 设置已填内容与编辑文字使用 BodyLarge 主色正文；辅助说明使用 BodySmall 次要色并增加间距，编辑面板在有明确边界的输入框下显示小号提示。
- 悬浮球预设色板保持固定顺序，选择只更新选中状态和预览；不将当前颜色插入色板首位。自定义颜色通过“更多颜色”选择，在悬浮球预览中呈现。
- 快捷动作只提供截图问答、框选问答、开始录音、结束录音、取消并丢弃录音与展开菜单，按屏幕、录音、基本操作分组。点开功能以底部列表多选手势，右侧对勾显示选中状态，取消/保存一次完成，不提供录音状态选择或冲突替换流程。程序固定适用条件；互斥占用项置灰，但整行保持可点击，仅用短 Toast 显示真正冲突的占用功能，连续点击取消旧提示，选择和面板不变。兼容功能可共用手势，保存时再次校验，禁止覆盖占用者。设置提供独立「实验室」入口，长按滑动的开关、等待、距离、动作圆大小和体验入口集中于此；实验性说明收在圆圈 i 中，快捷动作首页不介绍滑动。长按滑动默认关闭，保留已有开关状态、参数与绑定；开启后在「快捷动作」分配方向手势；关闭时完全隐藏三个方向、等待、距离、动作圆大小与方向摘要，不清除已设置方向。三个方向默认均未分配。开关旁圆圈 i 说明提供「体验」，参数选择器标出默认值。恢复默认只重置绑定，不改开关与参数。
- 长按滑动复用 48dp 触控范围和用户球体外观：按下约 100ms 缩至 96% 并提高不透明度，长按等待细环填充；就绪时轻震、约 150ms 回弹，圆形方向功能图标约 160ms 展开，方向选中反馈约 100ms 过渡，取消时约 120ms 淡出；执行动作前立即移除。长按后方向移动产生小幅椭圆形变，球中心不移动；超过滑动距离只预选方向，松手执行。未滑出时原地松手执行长按；滑出后回中松手取消，未绑定方向不执行。持续按住不自动执行，不提供选择倒计时。默认滑动距离 24dp，可选 16–40dp；动作圆直径默认 32dp，可选 28–40dp，均按 4dp 调整。动作圆大小与目标位置独立于球体大小，目标圆心距为 `max(48dp, 滑动距离 + 动作圆半径 + 8dp)`，默认 48dp；不要求拖至圆心。提示为不接收触摸的独立覆盖层，截图前立即移除。系统关闭动画时保留静态反馈，触觉尊重系统设置。真实服务和模拟指南共用触摸控制器、判定器和视图；指南提供示范及长按松手、三个方向和回中取消练习，不触发采集、请求或绑定保存。
- 普通长按成立与长按滑动就绪共用一次性触觉门控。优先使用标准长按反馈；系统反馈失败时，仅在视图可见、允许触觉且设备支持时请求预定义短触觉效果，使用触摸用途，不绕过系统关闭、免打扰或后台限制。平台设置与振动服务访问集中在独立适配器，指南隔离检查只对此类的指定平台读取放行，其他采集、请求与设置存储仍禁止。
- 悬浮球展开菜单不使用常态投影或按钮阴影。打开时以全屏触摸遮罩突出菜单，点外部或返回收起，不透传点击；Android 12 及以上使用系统允许的跨窗口模糊，并监听其运行时开关，不支持或关闭时使用加深遮罩。[系统模糊能力与限制](https://source.android.com/docs/core/display/window-blurs)。
- 小窗追问输入区默认收起，可在「结果窗口」设置中关闭。底部操作栏与标题栏统一为 42dp 高；标题栏操作从左到右为垃圾桶、固定窗口和在应用中打开，垃圾桶沿用标题栏图标按钮样式，直接丢弃整段当前会话并清理历史及媒体，不弹二次确认。底部左侧展开入口高 36dp、圆角 12dp，右侧为复制和收藏，右下角留出独立拉伸区域。左侧为浅强调底色、12sp 常规字重的「继续提问」文字及 14dp 箭头按钮；展开后显示「收起输入框」，有草稿时显示「继续编辑」，入口文字和图标保持强调色，提供操作及草稿的无障碍和悬浮说明。文字单行显示，在窄窗或大字号下省略，右侧操作区保持独立。停止和重试按需显示在请求状态旁，复制在没有回答时置灰。拉伸手柄独立固定在整个窗口右下角，展开或收起输入区都跟随窗口边界，并与操作栏及发送按钮的触控区域分开，不新增空白底栏。展开后问题输入框独占一行，使用 5dp 圆角细描边及框内提示，不使用浮动标签；下方同行排列图片选项、联网搜索和圆角矩形发送按钮，搜索/发送仍保留 48dp 触控区域。空白问题或请求/采集忙碌时发送置灰，输入有效文字且可发送时启用。收起隐藏整个输入区及分隔线，保留草稿并收起键盘。每次重新呼出按设置初始化，主题或旋转重建保留当前展开状态。
- 联网搜索选中时使用主题浅底色。设置定义默认值，窗口临时选择不改写设置，旋转、主题重建和悬浮会话移交保持选择。小窗发送与缩放保留独立操作区域；「复制最近回答」位于底部操作栏，完整聊天页的「复制整段会话」位于标题栏更多菜单。输入区不为角落缩放手柄预留右侧空白。
- 菜单在「最近悬浮对话」下方、底部图标栏上方显示「联网搜索」「使用默认提问方式」复选框，整行可点，切换保持菜单打开并持久保存。菜单联网选择只初始化后续新悬浮会话，首次沿用设置默认值；已有会话保持自己的选择。默认提问总开关不改写截图、录音、选中文字的分项设置。关闭总开关或对应分项后，采集完成的小窗直接展开输入区，窗口获得焦点后聚焦输入框并唤起键盘，覆盖输入区默认收起设置；内容滚动不能夺走编辑焦点。手动发送录音按输入的问题回答，不沿用仅转写或固定翻译输出；转入应用继续发送也保持该行为。录音上限的丢弃/确认策略继续有效，关闭总开关时禁止达到上限或确认保留后自动发送。
- 小窗固定采用不同图形：未固定为线框图钉，固定为实心图钉；同时更新选中状态和无障碍提示。颜色选择器的色相滑块使用连续取值，兼容 RGB 转换产生的小数色相。
- 截图链路先收起输入法并从 WindowManager 撤下所有悬浮窗口（包括固定窗口），保留原 View、草稿与滚动状态，经过两次 vsync 和短暂合成等待后建立新帧时间边界；复用既有 VirtualDisplay，替换 ImageReader 输出目标并关闭旧队列，防止取到包含菜单的旧图。成功、失败、旋转或共享结束均恢复仍有效的窗口；取图期间禁止重新显示小窗。空闲时及时关闭图像，避免堵塞生产者。框选窗口接收焦点并注册系统返回回调，返回手势、返回键和取消共用退出逻辑；窗口移除时注销回调。

字号使用 sp，尺寸和间距使用 dp；系统字体缩放、实际屏幕可用范围及用户保存的窗口几何会影响最终尺寸。原型尺寸用于默认布局，不覆盖用户外观与窗口设置。
